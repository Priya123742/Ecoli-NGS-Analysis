# NGS Analysis Project (E. coli Genome)

## Objective
To perform Next Generation Sequencing (NGS) data analysis of E. coli using a complete bioinformatics pipeline.

## Workflow
Quality Control – FastQC used for raw read checking  
Read Trimming – Trimmomatic used for cleaning reads  
Alignment – BWA used for mapping reads to reference genome  
Post-processing – SAMtools used for sorting and indexing  
Variant Calling – SAMtools mpileup used for detecting variants  
Visualization – IGV used for genome visualization  

## Tools Used
FastQC, Trimmomatic, BWA, SAMtools, IGV

## Files
aligned.bam → aligned sequencing reads  
variant.vcf → final variant results  

## Results
Successful alignment and variant detection of E. coli genome
